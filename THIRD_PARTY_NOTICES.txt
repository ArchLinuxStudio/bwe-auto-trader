Electron and Chromium runtime
-----------------------------
The Windows application embeds Electron 43.4.0, Chromium 150.0.7871.224, and
Node.js 24.18.1. Electron's license is installed as LICENSE.electron.txt.
Chromium and its bundled components use many independent licenses, preserved
in LICENSES.chromium.html. That inventory includes weak-copyleft components,
including FFmpeg under LGPL-2.1-or-later. Consult that HTML file for the exact
component-by-component terms, notices, and source locations.

This runtime inventory is reviewed for the Windows x64 v0.1.9 artifact only.
macOS and Linux public binaries require their own target-specific runtime audit.

Runtime source and build provenance:

  Electron: https://github.com/electron/electron/tree/v43.4.0
  Electron release: https://github.com/electron/electron/releases/tag/v43.4.0
  Electron build instructions:
    https://github.com/electron/electron/blob/v43.4.0/docs/development/build-instructions-gn.md
  Chromium source:
    https://chromium.googlesource.com/chromium/src/+/150.0.7871.224

Verification
------------
licenses/third-party-manifest.json is the machine-readable inventory. Build
gates compare it with the package-lock production closure, the installed
production tree, and the final packaged ASAR/unpacked dependency set. They also
verify the SHA-256 digest of every evidence file and require this notice file
and the evidence files to be present in the application package.

This notice is an engineering compliance record, not legal advice.
